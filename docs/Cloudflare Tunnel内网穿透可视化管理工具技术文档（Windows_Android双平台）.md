## 3\. 整体穿透技术原理（双平台通用）

设备无需公网IP、无需VPS，依托 Cloudflare 全球边缘网络实现内网穿透：

1. 客户端（Windows/Android）主动向外发起长连接，与 Cloudflare 边缘节点建立加密隧道

2. DNS 解析托管在 Cloudflare，域名流量自动路由至用户建立的隧道

3. CF 边缘节点流量通过隧道回传至本地内网服务

4. 所有流量为**出站主动连接**，无需本地端口对公网暴露，安全性极高

协议差异化原理：

- **七层协议（HTTP/HTTPS/WS）**：基于CF虚拟网络域名转发，免费、自动HTTPS证书、无需鉴权

- **四层TCP协议**：基于 Cloudflare Access 四层隧道转发，必须携带鉴权上下文，不支持裸端口暴露
